## Cómo ejecutar el proyecto

1. `git clone git@github.com:zorroe/HaloMusic.git`
2. `cd HaloMusic`
3. `npm i`
4. `npm run dev`

> Para utilizar el espejo de electron en China, ejecute: `npm config set electron_mirror=https://registry.npmmirror.com/-/binary/electron/`
